# 学刻番茄客户端 — 设计文档

- **日期**：2026-07-14
- **状态**：已确认
- **规范源**：仓库根目录 `agent.md`（实现以该文件为硬约束）

## 背景与目标

学刻是 PC 端番茄工作法客户端，面向学习效率：专注块推进任务，本地统计看见当日产出。

## 决策记录

| 议题 | 选择 |
|---|---|
| 桌面方案 | Electron |
| 前端 | React + TypeScript |
| 平台 | macOS + Windows |
| MVP | 经典番茄钟 + 任务联动 + 当日统计 |
| 存储 | 仅本地 |
| 语言 | 中文为主，预留 i18n |

## 架构摘要

- 主进程：权威计时、托盘、通知、持久化、IPC
- 预加载：`contextBridge` 受控 API
- 渲染：专注台 / 任务 / 今日 / 设置
- 安全：`contextIsolation: true`，渲染侧无 Node 集成

## 界面与数据

见 `agent.md` 第 5–6 节。统计口径：仅已完成的 focus 会话计入完成番茄。

账号与云同步、系统级拦截、Linux、完整英文 UI、插件生态。
